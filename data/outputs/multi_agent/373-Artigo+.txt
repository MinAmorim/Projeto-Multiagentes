Neste estudo, os autores compararam as ferramentas EvoSuite e Randoop para geração de casos de testes automatizados, focando na cobertura de código e testes de mutação. Utilizando a metodologia de Engenharia de Software Baseada em Evidências (ESBE), os experimentos foram conduzidos com as ferramentas aplicadas ao projeto Apache Commons Net, utilizando a ferramenta JaCoCo para análise de cobertura de linha e Pitest para geração e execução de mutantes. Os resultados indicaram que a ferramenta EvoSuite obteve maior cobertura de código (94,2%) mas menor capacidade de identificar mutações (36,5%), enquanto o Randoop apresentou menor cobertura de código (65,4%) mas maior taxa de eliminação de mutantes (42,2%). Conclui-se que ambas as ferramentas ainda precisam ser aprimoradas para melhorar a qualidade dos casos de teste gerados.
