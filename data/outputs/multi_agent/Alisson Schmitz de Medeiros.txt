O artigo aborda a necessidade de garantir a qualidade do software em um contexto onde a automação de testes se torna cada vez mais relevante, especialmente para aplicações móveis. Os autores, Alisson Schmitz de Medeiros e Matheus Leandro Ferreira, destacam que a implementação de testes de software é um desafio devido à complexidade dos sistemas e às dificuldades nas etapas de desenvolvimento. A automação do teste de software é considerada crucial para aumentar a produtividade e reduzir o tempo gasto em testes repetitivos, embora os testes manuais ainda sejam necessários.

A metodologia utilizada caracteriza-se como aplicada e de base tecnológica, visando desenvolver uma ferramenta para suporte à automação de testes em dispositivos móveis. O estudo envolve a criação de casos de testes que navegam em elementos de aplicativos, realizam comparações de imagens e apresentam resultados para analistas de testes. Para a execução dos testes, a pesquisa utiliza o software Appium, que permite a instalação do aplicativo configurado, a interação com os elementos durante os testes e a captura de tela para exibição dos resultados. Ferramentas como Android Studio e UI Automator Viewer são empregadas para análise dos componentes do aplicativo, e a comparação de imagens é realizada pixel a pixel, verificando diferenças entre as imagens geradas durante os testes e as imagens de referência armazenadas. Um banco de dados MySQL é utilizado para estruturar e controlar os dados da pesquisa.

Os resultados indicam que a ferramenta desenvolvida é capaz de diminuir o esforço em testes repetitivos simples e fornece feedback visual claro sobre a execução dos testes. No entanto, os autores ressaltam que a ferramenta ainda não está preparada para replicação de casos de teste em diferentes versões ou dispositivos, o que limita sua aplicabilidade. Além disso, a pesquisa sugere que a automação de testes em dispositivos móveis não é uma prática comum nas empresas, apontando para uma área que pode ser aprofundada em estudos futuros. A conclusão do trabalho reafirma a possibilidade de melhorar processos e aumentar a cobertura de testes em aplicativos, destacando a importância da automação na engenharia de software.
