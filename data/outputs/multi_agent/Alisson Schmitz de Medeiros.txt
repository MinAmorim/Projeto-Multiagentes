O artigo de Alisson Schmitz de Medeiros e Matheus Leandro Ferreira aborda a necessidade de garantir a qualidade do software, especialmente em dispositivos móveis, através da automação de testes. Os autores destacam que "o teste de software é essencial para o desenvolvimento de um produto qualificável no mercado" e que "o processo de testes nem sempre foi priorizado como uma atividade principal no desenvolvimento de uma solução". Além disso, mencionam que "a implementação é um grande desafio devido à alta complexidade dos sistemas e às inúmeras dificuldades relacionadas às etapas de desenvolvimento".

A lacuna científica identificada pelos autores é que a automação de testes em dispositivos móveis "não seja muito comum em empresas" e que "espera-se que a pesquisa seja aprofundada em uma área não muito utilizada na engenharia de software". Para trabalhos futuros, sugerem "realizar estudos para replicação de casos de teste reutilizando em emuladores/dispositivos diferentes" e "realizar estudo para reaproveitamento de scripts para IOS".

A metodologia utilizada caracteriza-se como aplicada e de base tecnológica, com o objetivo de desenvolver uma ferramenta para suporte à automação de testes em dispositivos móveis. Os autores afirmam que "a finalidade é criar uma ferramenta para suporte a automação de testes em dispositivos móveis", e para isso, foram criados casos de testes que "são capazes de navegar em elementos de um aplicativo, realizando comparações de imagens e demonstrando seus resultados para o analista de testes". O desenho do estudo inclui a comunicação com o software Appium, que é responsável pela instalação do aplicativo configurado e pela interação com os elementos durante os testes, conforme descrito: "Após a preparação dos casos de testes, faz-se necessário a comunicação com o software Appium".

Os materiais utilizados incluem o Android Studio, que fornece ferramentas como o UI Automator Viewer e um emulador para a execução dos testes. Os autores mencionam que "na preparação e execução dos casos de teste, foram utilizadas ferramentas do software Android Studio, como o UI Automator Viewer e o emulador respectivamente". A comparação de imagens é uma técnica central na análise dos resultados, onde "a comparação de imagens realizada na ferramenta, é feita verificando o RGB pixel a pixel da imagem, comparando as duas imagens". O banco de dados utilizado para armazenar informações foi desenvolvido no MySQL, conforme indicado: "O banco de dados desta pesquisa foi desenvolvido e estruturado no MySQL na sua versão 8.0.30".

Os resultados da pesquisa indicam que a ferramenta desenvolvida "tem a capacidade de atender os objetivos apresentados, conseguiu diminuir o esforço gasto em testes repetitivos simples e demonstrou os resultados de forma clara". A metodologia incluiu a criação de casos de testes que "são capazes de navegar em elementos de um aplicativo, realizando comparações de imagens e demonstrando seus resultados para o analista de testes". A comunicação com o software Appium foi essencial, pois "faz-se necessário a comunicação com o software Appium" para a instalação do aplicativo e interação durante os testes. A comparação de imagens foi uma técnica central, onde "a comparação de imagens realizada na ferramenta, é feita verificando o RGB pixel a pixel da imagem, comparando as duas imagens". 

Os resultados sugerem que a automação de testes em dispositivos móveis pode ser uma alternativa viável, embora "não seja muito comum em empresas", e os autores esperam que a pesquisa seja aprofundada em "uma área não muito utilizada na engenharia de software". Para trabalhos futuros, eles sugerem "realizar estudos para replicação de casos de teste reutilizando em emuladores/dispositivos diferentes" e "realizar estudo para reaproveitamento de scripts para IOS".
