O objetivo deste trabalho é melhorar a qualidade de aplicações web, cujos códigos fonte não tiveram testes realizados desde o começo do desenvolvimento, e dessa forma prover mais segurança na realização de modificações em código que podem impactar em várias partes do projeto, mediante metodologia de geração de testes ad-hoc automatizados. A metodologia adotada envolve a criação de uma ferramenta automatizada para geração de testes ad-hoc para aplicações web, visando garantir a usabilidade e a integridade dos sistemas, mesmo em aplicações que não foram testadas desde o início do desenvolvimento. A solução proposta por este trabalho é um projeto de interface de linha de comando (CLI), chamado de Cytestion, capaz de gerar um arquivo de testes, que realiza testes ad-hoc na aplicação web alvo, de forma automática. Utilizando corretamente os componentes do Ant Design, pode-se ter uma identificação única para ser usada em testes, em tags selecionadas e diretamente relacionadas aos componentes que as originaram. A ferramenta foi desenvolvida pensando em sua utilização como submodule num sistema de controle de versão como git, durante o desenvolvimento de aplicações web. A avaliação da ferramenta foi feita a partir do desenvolvimento de uma simples aplicação web, que possibilita o cadastro de informações para organização financeira, chamada Expense Organizer. A ferramenta gerou testes que alcançaram 100% das interfaces da aplicação, preenchendo campos e realizando a submissão, e detectando falhas introduzidas no código fonte da aplicação. O Cytestion foi desenvolvido para garantir a usabilidade da aplicação e a integridade dos sistemas, proporcionando a detecção de falhas rapidamente, além de garantir a usabilidade da aplicação.
