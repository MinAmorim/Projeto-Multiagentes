O artigo de Thiago Santos de Moura, intitulado "Automação de testes em aplicações web utilizando uma abordagem ad-hoc", aborda a necessidade de melhorar a qualidade de aplicações web que não possuem testes implementados desde o início do desenvolvimento. Os autores afirmam que "o objetivo deste trabalho é melhorar a qualidade de aplicações web, cujos códigos fonte não tiveram testes realizados desde o começo do desenvolvimento". Eles destacam que a automação de testes manuais, especialmente os ad-hoc, poderia resultar em "maior completude e mais segurança", uma vez que "alguns desses testes manuais, especialmente os ad-hoc, poderiam ser automatizados".

A metodologia utilizada no artigo é uma abordagem ad-hoc para a automação de testes em aplicações web, focando na geração automática de testes para sistemas que não possuem testes implementados desde o início do desenvolvimento. A solução proposta é uma ferramenta chamada Cytestion, que gera testes automatizados a partir da análise do código HTML da aplicação. Os autores afirmam que "a solução proposta por este trabalho é um projeto de interface de linha de comando (CLI), chamado de Cytestion, capaz de gerar um arquivo de testes, que realiza testes ad-hoc na aplicação web alvo, de forma automática". A ferramenta utiliza o framework Cypress para a execução dos testes, permitindo a criação de testes E2E, de integração e de unidade.

O processo de geração de testes é dividido em quatro etapas: ponto inicial, análise, geração e limpeza. Durante a análise, "o arquivo de testes é gerado utilizando técnicas de construção e manipulação de strings com Node.js", e a busca de strings relevantes é otimizada pelo algoritmo de Aho-Corasick. A geração de testes é baseada nos identificadores encontrados, com o objetivo de "agregar novos blocos de códigos no arquivo de testes, que possam percorrer a aplicação web através dos cliques em botões ou links". Após a geração, a etapa de limpeza remove testes duplicados e formata o código gerado, resultando em um arquivo de testes final que é utilizado para validação da aplicação.

A avaliação da ferramenta demonstrou que "todas as possibilidades descritas anteriormente foram alcançadas, para todas as entidades do sistema, resultando em 100% da cobertura de interfaces da aplicação web desenvolvida". Além disso, a ferramenta se mostrou eficaz na detecção de falhas, onde "ao executar o Cytestion o comando de geração retorna um erro, indicando que pelo menos um dos testes falhou durante a execução". A abordagem proposta, portanto, contribui para a melhoria da qualidade de aplicações web, especialmente aquelas que não possuem testes desde o início do desenvolvimento, proporcionando "maior completude e mais segurança" na execução dos testes.
