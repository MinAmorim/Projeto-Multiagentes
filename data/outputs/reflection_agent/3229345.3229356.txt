**Resumo**

O teste de software é uma atividade crucial no desenvolvimento, representando de 40% a 60% dos custos de um projeto. Este artigo aborda a automação de testes em uma Fábrica de Testes, descrevendo a experiência adquirida na automação de testes de dois softwares, identificando desafios, soluções e lições aprendidas. A metodologia utilizada incluiu a implementação de testes automatizados com a linguagem Java e ferramentas como Selenium e JUnit. Os resultados mostraram que, embora a automação inicial tenha demandado um esforço significativo de 594 homens-horas para o Software A e 86 homens-horas para o Software B, houve uma redução considerável no tempo de execução dos testes, passando de 18 horas para cerca de 5 horas no Software A e de 2 horas para 29 minutos no Software B. As contribuições deste trabalho incluem um processo estruturado para automação de testes e cinco lições aprendidas que podem beneficiar tanto a indústria quanto a academia, além de direcionar futuras pesquisas na área.
