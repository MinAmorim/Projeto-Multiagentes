O trabalho de conclusão de curso de Thiago Santos de Moura desenvolve uma ferramenta chamada Cytestion para automatizar testes ad-hoc em aplicações web, utilizando a tecnologia React e o framework de testes Cypress. A ferramenta identifica elementos interativos na interface, gera testes que simulam a interação do usuário e executa esses testes automaticamente. O Cytestion é projetado para ser usado como um submodule em sistemas de controle de versão, permitindo a geração de testes após a conclusão de issues de desenvolvimento.

A solução proposta é um projeto de interface de linha de comando (CLI) que gera arquivos de testes utilizando funções personalizadas do Cypress. Essas funções facilitam a seleção e interação com elementos da interface, como campos de entrada e botões. O Cytestion também implementa um algoritmo de pesquisa de strings para identificar elementos únicos na interface, permitindo a geração de testes que cobrem todos os fluxos de utilização possíveis.

A avaliação da ferramenta foi realizada em uma aplicação web de demonstração, onde o Cytestion gerou testes que cobriram 100% das interfaces da aplicação, incluindo fluxos de CRUD em várias abas. A ferramenta também detectou falhas introduzidas no código, indicando sua eficácia como teste de regressão.

Os resultados demonstram que o Cytestion pode automatizar a geração de testes ad-hoc, reduzindo a necessidade de testes manuais e aumentando a cobertura de testes em aplicações web.
