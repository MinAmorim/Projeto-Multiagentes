**Resumo**

O desenvolvimento de aplicações web frequentemente enfrenta desafios relacionados à qualidade do software, especialmente no que diz respeito à validação e verificação de funcionalidades. Este trabalho tem como objetivo aprimorar a qualidade de aplicações web que não possuem testes automatizados, propondo uma metodologia para a geração de testes ad-hoc automatizados. Para isso, foi desenvolvida a ferramenta Cytestion, uma interface de linha de comando que utiliza o framework Cypress para criar testes end-to-end (E2E) de forma automatizada. O método proposto envolve a análise do código HTML da aplicação, a identificação de elementos interativos e a geração de testes que simulam a navegação do usuário. Os resultados demonstraram que a ferramenta alcançou 100% de cobertura das interfaces da aplicação testada, permitindo a detecção de falhas e a realização de testes de regressão de maneira eficiente. A contribuição deste trabalho reside na automação do processo de testes, reduzindo custos e tempo de desenvolvimento, além de garantir a usabilidade e a qualidade das aplicações web.
