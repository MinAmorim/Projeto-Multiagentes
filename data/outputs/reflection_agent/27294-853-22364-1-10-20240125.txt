Este artigo aborda a crescente necessidade de testes de segurança em aplicações Android, dada a ampla gama de aplicativos disponíveis. O objetivo principal é apresentar uma metodologia de testes de segurança que seja acessível tanto para profissionais de segurança quanto para testadores de software, utilizando diretrizes da OWASP, como o Mobile Application Security Verification Standard (MASVS) e o Mobile Application Security Testing Guide (MASTG). A metodologia proposta inclui a análise inicial dos requisitos, especificação dos procedimentos de teste, execução dos testes e análise dos resultados, seguindo a norma ISO 829 para documentação.

Os resultados obtidos a partir da aplicação da metodologia em cinco aplicativos demonstraram a presença de vulnerabilidades, como uso inadequado da plataforma, armazenamento de dados inseguros e comunicação insegura. Cada vulnerabilidade foi relacionada a requisitos de segurança do MASVS, evidenciando a importância de seguir boas práticas de programação para mitigar riscos. Este trabalho discute a metodologia proposta, promovendo uma abordagem para a identificação e resolução de vulnerabilidades em aplicações móveis.
