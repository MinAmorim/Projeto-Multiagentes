**Resumo**

O crescente uso de aplicações móveis na plataforma Android suscita preocupações significativas em relação à segurança, uma vez que vulnerabilidades podem afetar milhões de usuários. Este trabalho tem como objetivo apresentar uma metodologia padronizada para a realização de testes de segurança em aplicações Android, fundamentada nas diretrizes do Open Web Application Security Project (OWASP), especificamente nos guias Mobile Application Security Verification Standard (MASVS) e Mobile Application Security Testing Guide (MASTG). A metodologia proposta abrange a análise inicial dos requisitos de segurança, a especificação de procedimentos de teste, a execução dos testes e a análise dos resultados, seguindo a norma ISO 829 para documentação. Os testes foram aplicados em cinco aplicações, resultando na identificação de vulnerabilidades críticas, como uso inadequado da plataforma, armazenamento inseguro de dados e comunicação insegura. A contribuição deste trabalho reside na formalização de uma abordagem que integra as áreas de testes de software e segurança, facilitando a compreensão e a aplicação de testes de segurança por profissionais de ambas as disciplinas. Além disso, enfatiza-se a importância da padronização na execução de testes para assegurar a segurança das aplicações móveis.
