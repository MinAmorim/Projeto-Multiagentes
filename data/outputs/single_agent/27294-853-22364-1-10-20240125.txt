O artigo "Uma Abordagem para Testes de Segurança em Aplicações Android" aborda a crescente necessidade de testes de segurança em aplicações móveis, especialmente no contexto do Android, onde vulnerabilidades podem impactar usuários globalmente. O objetivo do trabalho é apresentar uma metodologia didática para a condução de testes de segurança em aplicações Android, utilizando os guias da Open Web Application Security Project (OWASP), especificamente o Mobile Application Security Verification Standard (MASVS) e o Mobile Application Security Testing Guide (MASTG).

A metodologia proposta é estruturada em cinco etapas: análise inicial dos requisitos, especificação dos procedimentos de teste, execução dos testes, análise dos resultados e indicações de boas práticas. Os testes são realizados em cinco aplicações no formato APK, que abrangem as 10 vulnerabilidades listadas no OWASP Mobile Top 10. Os resultados indicam a presença de vulnerabilidades significativas, como uso inadequado da plataforma, armazenamento de dados inseguro e comunicação insegura, evidenciando a importância de seguir as diretrizes de segurança.

A contribuição do artigo reside na formalização dos testes de segurança em um formato acessível tanto para profissionais de segurança quanto para testadores de software, promovendo uma melhor compreensão e aplicação das diretrizes de segurança. Além disso, o uso da norma ISO 829 para documentar os testes é destacado como uma prática que pode aumentar a clareza e a padronização no processo de verificação de segurança em aplicações móveis.
