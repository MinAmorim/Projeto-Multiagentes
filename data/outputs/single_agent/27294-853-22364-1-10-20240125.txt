O artigo propõe uma abordagem para testes de segurança em aplicações Android, utilizando a metodologia da Open Source Foundation for Application Security (OWASP). Os autores desenvolveram uma especificação de testes de segurança baseada em dois guias da OWASP: Mobile Application Security Verification Standard (MASVS) e Mobile Application Security Testing Guide (MASTG). Essa metodologia foi formalizada seguindo o padrão ISO 829, com o objetivo de padronizar os testes de segurança para profissionais de software e segurança.

A metodologia inclui cinco etapas: análise inicial dos requisitos, especificação dos procedimentos de teste, execução dos testes, análise dos resultados e indicações de boas práticas. Os procedimentos de teste foram definidos para verificar 10 vulnerabilidades do OWASP Mobile Top 10, cobrindo categorias como uso inadequado da plataforma, armazenamento de dados inseguro e comunicação insegura.

Os autores utilizaram cinco aplicações Android para testar a metodologia, identificando vulnerabilidades significativas. As vulnerabilidades descobertas incluíram uso indevido de plataforma, armazenamento de dados inseguro e comunicação insegura. Os resultados indicaram que a metodologia pode ser eficaz em identificar vulnerabilidades críticas, mas também que as práticas de programação inadequadas são frequentes.

A metodologia proposta foi aplicada em cinco aplicações Android, identificando vulnerabilidades do OWASP Mobile Top 10. Os resultados mostraram que a abordagem pode ser eficaz em identificar vulnerabilidades críticas, mas também que as práticas de programação inadequadas são frequentes. A padronização dos testes, seguindo a ISO 829, foi apresentada como uma boa alternativa para formalizar os testes e garantir resultados mais confiáveis. O artigo sugere que a padronização dos testes é importante para minimizar o número de vulnerabilidades críticas em projetos de desenvolvimento de software.
