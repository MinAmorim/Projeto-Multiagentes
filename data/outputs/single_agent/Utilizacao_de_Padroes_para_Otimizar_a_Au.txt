O artigo apresenta o framework FuncTest, desenvolvido para otimizar a automação de testes funcionais de software. O FuncTest utiliza padrões de projeto, como Factory Method e DAO, além de técnicas como Data-driven e Keyword-driven, para melhorar a reutilização e manutenção dos scripts de teste. A arquitetura MVC é adotada para desacoplar a execução dos scripts dos dados de teste, permitindo a criação de procedimentos de teste flexíveis. O framework é configurado através de arquivos XML, facilitando a manutenção e a inclusão de novos casos de teste. Os padrões Factory Method são aplicados para a criação de scripts e objetos DAO, enquanto o DAO encapsula a acesso aos dados, permitindo a utilização de diferentes fontes de dados. O FuncTest foi implementado em um processo de desenvolvimento aderente ao CMM nível 2, trazendo benefícios como desacoplamento, independência entre scripts e dados, modularização, e controle centralizado de erros. Futuros trabalhos incluem a implementação do padrão Strategy e a adaptação para o model-based testing.
