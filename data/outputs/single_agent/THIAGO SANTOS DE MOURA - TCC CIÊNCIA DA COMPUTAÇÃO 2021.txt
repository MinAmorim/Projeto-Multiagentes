**Resumo**

O desenvolvimento de aplicações web frequentemente enfrenta desafios relacionados à qualidade do software, especialmente na validação e verificação de funcionalidades. Este trabalho tem como objetivo melhorar a qualidade de aplicações web que não possuem testes automatizados, propondo uma metodologia de geração de testes ad-hoc automatizados. Para isso, foi desenvolvido o Cytestion, uma ferramenta de linha de comando que utiliza o framework Cypress para criar testes end-to-end (E2E) de forma automática. O método envolve a análise do código HTML da aplicação, identificação de elementos interativos e geração de testes que percorrem todos os fluxos de utilização possíveis. Os resultados demonstraram que a ferramenta alcançou 100% de cobertura das interfaces da aplicação testada, além de ser eficaz na detecção de falhas introduzidas intencionalmente no código. A contribuição deste trabalho reside na automação do processo de testes, reduzindo o custo e o tempo de desenvolvimento, e proporcionando maior segurança nas modificações do código, o que é essencial para a evolução contínua de aplicações web.
